# Prato Falado

Diário de calorias para iPhone (PWA): registro por ditado ("200 g de arroz, 2 ovos, 1 concha de feijão"),
código de barras com câmera ao vivo, metas diárias, macros, micronutrientes e resumo semanal.

- Alimentos: [TACO — Tabela Brasileira de Composição de Alimentos (Unicamp)](https://www.nepa.unicamp.br/taco/), via [taco-api](https://github.com/raulfdm/taco-api)
- Produtos: [Open Food Facts](https://world.openfoodfacts.org) (dados sob licença ODbL)
- Registros: no aparelho e, com conta, sincronizados no Supabase (tabela `kv`, ver `schema.sql`)

Valores são estimativas para acompanhamento pessoal e não substituem orientação de nutricionista.
